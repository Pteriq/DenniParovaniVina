# Denní párování vína 🍷

Malá interaktivní hra v češtině. Každý den je nové jídlo a 10 vín – některá se k jídlu hodí skvěle, jiná vůbec.

- Po výběru vína uvidíš skóre párování, popis vína a krátké vysvětlení.
- Zobrazí se i nejlepší volba dne a hodnocení všech 10 vín.
- Jeden pokus denně, nová výzva vždy o půlnoci.
- Historie a statistiky se ukládají v prohlížeči (localStorage).

Připraveno 40 jídel (40 dní bez opakování od 19. 11. 2026, kapr na Štědrý den), poté se jídla cyklicky opakují v novém pořadí.

## Spuštění

Stačí otevřít `index.html` v prohlížeči – žádná instalace ani server nejsou potřeba.
